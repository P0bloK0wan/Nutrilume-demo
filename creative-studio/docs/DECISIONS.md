# Decisões

1. Projeto separado: preservar Nutrilume e seus dados; não publicar suas alterações durante esta nova missão.
2. Orquestração nativa: agentes reais disponíveis resolvem planejamento, pesquisa, produção e revisão sem credenciais novas. Perfis documentados são reutilizáveis, não processos fictícios.
3. Dependências mínimas: uma stack web e uma de vídeo; Blender já instalado. Não instalar CrewAI, BMAD runtime, OpenAI Agents SDK e Deep Agents ao mesmo tempo.
4. Direção AURA / Object01: conceito original de luminária em porcelana, alumínio e luz âmbar; usar a mesma linguagem nas quatro demonstrações para demonstrar integração.
5. Render CPU: três CPUs, limitar duração/amostras e registrar qualidade. WebGL via software não prova desempenho em celulares físicos.
6. MCP: avaliar código/permissões do Blender MCP, mas usar CLI local com scripts próprios enquanto não houver necessidade de abrir socket.
7. Artefatos reais: MP4 conferido por ffprobe, fonte editável, imagens inspecionadas e testes de navegador. Não alegar domínio de tópicos que ficaram apenas estudados.
