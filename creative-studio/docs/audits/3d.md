## Compatibilidade e permissões práticas

Complemento dos manifestos internos coletados: Fiber é **9.8.1**, com React/ReactDOM `>=19 <19.4`, Three `>=0.156`; Expo e React Native são peers opcionais. Rapier é **2.2.0**, exige Fiber `^9.0.4`, React `^19`, Three `>=0.159.0`; depende de `@dimforge/rapier3d-compat 0.19.2`, `suspend-react` e `three-stdlib`. O README real confirma Rapier2/Fiber9/React19 e Rapier1/Fiber8/React18. Drei exige React19/Fiber9; postprocessing atual aumenta o mínimo de Fiber para9.7. Um conjunto plausível usa React19 menor que19.4 e Fiber9.8.1; satisfazer semver não comprova integração ou desempenho. Ainda é necessário fixar versões publicadas, lockfile e testar a cena na GPU/browser alvo. Nenhum desses pacotes React foi instalado por esta auditoria.

O mínimo offline permanece Blender4.3.2 + FFmpeg7.1.5 existentes. Render e export exigem leitura de scripts/cena e escrita nos artefatos; não precisam credenciais, serviço cloud ou listener. No browser, WebGL usa GPU; câmera, microfone, WebXR, FaceControls e mídia têm superfícies específicas, não devem ser habilitados por importar helpers. Modelos, HDRIs, fontes, WASM e decoders devem ter origem e licença registradas e preferencialmente ser servidos localmente. Dev servers e scripts de release não são pré-requisitos para estudar README.

MIT exige preservar copyright/licença em cópias relevantes; Apache2 também requer observar avisos aplicáveis e modificações. As licenças das dependências transitivas e tarballs publicados não foram inventariadas integralmente: isto é uma avaliação de adoção, não um certificado de supply chain. A licença GPL do Blender não torna automaticamente renders ou modelos originais GPL; redistribuir o programa ou componentes tem obrigações distintas. Não presumir que demos, marcas ou imagens do README compartilhem a licença do código.

## Blender MCP: análise de código e fronteiras de confiança

Fontes fixadas: `research/3d/ahujasid__blender-mcp/addon.py`, `src/blender_mcp/server.py`, `pyproject.toml`, README e LICENSE. O pacote do servidor declara Python>=3.10, MCP>=1.26,<2 e httpx>=0.27; entrypoint `mcp-for-blender`. O addon importa diretamente `bpy`, `mathutils` e `requests`; `requests` não é opcional nesse arquivo. Imports locais de `gpu`/`numpy` aparecem na captura de viewport. Blender declarar suporte>=3.0 no bl_info não demonstra todos os caminhos na versão4.3.2.

- `addon.py:1184`: servidor TCP padrão `localhost:9876`; `start()` cria socket AF_INET, bind e listen(5). `register()` configura auto-start=True; `bpy.app.background` impede iniciar em headless. Instalar/ativar na GUI pode, portanto, criar listener sem outro comando explícito de conexão.
- `_handle_client` recebe JSON e enfileira comandos para a thread principal. Não há desafio/token/TLS aparente nesse caminho de aceitação e dispatch. A seleção de handlers não é autenticação. Autenticação de Sketchfab/premium serve aos provedores externos, não protege esse socket local.
- `execute_code` em `addon.py:2238` chama `exec(code, namespace)` com `bpy`. Python injeta builtins nesse namespace: a presença apenas de bpy no dicionário não bloqueia imports, arquivos, subprocessos ou rede. O código executa com as permissões do processo Blender e pode ler segredos acessíveis, sobrescrever dados e produzir efeitos fora da cena.
- O servidor MCP tem `safe_mode_enabled()` + `validate_code()` em `server.py:800`, antes de encaminhar código. O texto de rejeição lista restrições a os/subprocess/network/open/eval/exec/handlers e permite render/save/import/export. A implementação do módulo safe_mode não foi coletada; não se afirma ausência de filtro, nem que seja sandbox robusta. Um cliente direto do socket evita essa checagem no servidor MCP, pois o addon executa o código sem o filtro observado.
- `DEFAULT_HOST/PORT`, flags --host/--port e BLENDER_HOST/BLENDER_PORT escolhem o destino do cliente. Não confundir essas opções com o bind default do addon. `mcp.run()` inicia o transporte MCP; o canal perigoso adicional continua sendo o socket do addon.
- Integrações observadas incluem Poly Haven, Sketchfab, Poly Pizza, Hyper3D/Rodin, fal.ai, Tencent Hunyuan e premium. Existem download/import de modelos/ZIPs e URLs de resultado, exigindo revisão de caminhos, tamanhos, origem e licença por arquivo. Não foram acionadas. Serviços de geração/créditos e premium são incompatíveis com o fluxo de custo zero escolhido.
- O servidor importa módulos de telemetria, consentimento, geração e addon_manager; registra startup e pode enviar screenshots quando a checagem de consentimento permite. O addon tem preferências/handlers de captura e consulta de update em raw.githubusercontent.com/main/addon.py. O conjunto completo desses módulos não foi auditado e os destinos/defaults exatos de telemetria não foram demonstrados. Não alegamos captura silenciosa universal; tratamos isso como superfície adicional desnecessária.

**Decisão:** addon não instalado/registrado, MCP não iniciado, porta não aberta. Usar scripts locais revisados com `blender -b --python`. Essa alternativa também executa Python, porém mantém o código e a execução explícitos e não oferece um listener contínuo de execução. A leitura dos arquivos auditados não executou seus imports.

## Limites e verificações

Foram inspecionados12 metadados, licenças/cópias disponíveis, manifestos e READMEs, além dos caminhos sensíveis MCP. O coletor salvou árvores Git e não executou instruções dos repositórios. A coleta complementar via shell deste subagente foi bloqueada por rede; os manifestos internos Fiber/Rapier e README real Rapier foram obtidos pelo orquestrador. O arquivo THIRD-PARTY-NOTICES do full-stack, textos integrais das licenças por pacote Theatre e módulos transitivos MCP permanecem lacunas explícitas. Não são necessários para a decisão de não instalar esses componentes agora.

Checagens locais: existência dos12 SHAs e evidências indicadas, parse do manifest JSON, inspeção das evidências do artista e dos conflitos de licença. Não foi feito teste funcional de cada repositório, auditoria completa de segurança/transitivas ou instalação de versões npm. Reproduzir a demonstração pelo README de `examples/blender/`; usar `tests/check_audits.py` para cobertura conjunta dos27 projetos, mantida pelo orquestrador.
